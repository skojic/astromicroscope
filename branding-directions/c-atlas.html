Direction C · Brand snapshot

A school, not a salon. The four elements become a colour code, now built only from the brief's palette: fire is gold, earth is sand beige, air is sky blue, water is deep blue, all on a soft beige page. It is the most natural fit for an education-first brand, because the code maps onto course levels, carousels and workbooks.
