# Content collections

Editorial content lives in the language folders (`sr/`, `en/`) and the collections defined in
`src/content.config.ts` (`articles`, `horoscope`, `pages`, `videos`). The schema and the language-pair
rules are owned by M00; the entries are the deliverables of M02, M06, M07, M08, M09 and M14
(see `plan/contracts.md`). A file that is not in a collection folder is ignored by the build.
