# SEO checklist

Run per template and for every new page type, in both languages.

- [ ] Unique title and meta description; main topic first; both languages
- [ ] Exactly one H1; headings follow the questions people search for
- [ ] The answer to the page's question is in the first paragraph
- [ ] Canonical points to itself
- [ ] hreflang: sr, en and x-default, with return links on both pages
- [ ] In `sitemap.xml` with its alternates; not blocked by robots.txt; no `noindex` by mistake
- [ ] Structured data valid (Rich Results Test, Schema Markup Validator) and matching the visible text
- [ ] Breadcrumbs visible and in structured data
- [ ] Internal links: linked from its hub; links to related pages with descriptive anchor text
- [ ] Author, date published and date updated on articles
- [ ] Images: descriptive file name, alt text, dimensions, modern format
- [ ] Open Graph and Twitter tags with a 1200×630 image
- [ ] Content present in the HTML without JavaScript (check view-source or a no-JS fetch)
- [ ] robots.txt allows Googlebot, Bingbot and OAI-SearchBot (user-agent names verified in vendor docs)
